BirthDay OS

Политика конфиденциальности

Последнее обновление: 6 августа 2026

BirthDay OS — приложение для iOS, которое показывает обратный отсчёт до дня рождения и статистику по прожитому и оставшемуся времени. Эта страница объясняет простым языком, какие данные приложение использует и что с ними происходит.

Какие данные вводятся в приложении

  • Имя (по желанию, можно не указывать)
  • Дата рождения
  • Желаемая продолжительность жизни (число лет)
  • Список желаний (вишлист) — по желанию пользователя

Где хранятся данные

Все данные хранятся только локально на твоём устройстве (в защищённом хранилище iOS). Приложение не использует сервер, не имеет аккаунтов и не передаёт данные куда-либо через интернет.

Дата рождения и имя также копируются в общее хранилище для виджета приложения на главном экране iOS (App Group) — это тоже происходит полностью на устройстве, без передачи в сеть.

Уведомления

С твоего разрешения приложение планирует локальные напоминания (например, за 30 дней до дня рождения). Эти уведомления формируются и показываются самим устройством — сторонние серверы push-уведомлений не используются.

Аналитика и реклама

Приложение не использует сторонние SDK аналитики, рекламные сети или трекинг поведения пользователя.

Передача данных третьим лицам

Приложение не передаёт никакие данные третьим лицам, потому что не отправляет данные никуда за пределы устройства.

Удаление данных

Ты можешь удалить свои данные в любой момент:

  • через пункт меню «Сменить пользователя» в приложении — удалит профиль и вишлист;
  • полным удалением приложения с устройства — сотрёт все данные, включая хранилище виджета.

Дети

Приложение не предназначено для сбора данных о детях без ведома родителей и не запрашивает данные, выходящие за рамки того, что пользователь вводит о себе самостоятельно.

Изменения политики

При изменении этой политики дата обновления наверху страницы будет актуализирована.
